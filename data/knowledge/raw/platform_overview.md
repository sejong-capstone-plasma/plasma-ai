# Plasma AI 플랫폼 개요

Plasma AI는 반도체 플라즈마 식각(ETCH) 공정에 특화된 AI 분석 플랫폼이다.
사용자가 자연어로 공정 조건을 입력하면, 시스템이 의도를 분류하고 예측·최적화·비교·질의응답 기능을 수행한다.
현재는 ICP(Inductively Coupled Plasma) 기반의 식각 공정만 지원한다.


---

# 지원 태스크 유형

시스템은 사용자의 입력을 다섯 가지 태스크로 분류한다.

## PREDICTION (예측)

사용자가 특정 공정 조건에서의 식각 성능을 예측 요청할 때 분류된다.

예시 입력:
- "pressure 5 mTorr, source 300 W, bias 50 W 예측해줘"
- "etch rate가 어느 정도 나올까?"
- "위 조건에서 source power 100 W 올려서 예측해줘"

동작: 입력 파라미터 → XGBoost 모델로 ion_flux, ion_energy 예측 → etch_score 계산 → LLM이 한국어 설명 생성

## OPTIMIZATION (최적화)

사용자가 현재 조건보다 더 높은 etch_score를 내는 공정 조건을 찾을 때 분류된다.

예시 입력:
- "etch rate를 더 향상할 수 있을까?"
- "개선 방안이 있을까?"
- "그 조건에서 성능 개선해줘"
- "현재 ER도 보고 개선안도 알려줘" (예측+최적화 동시 요청도 OPTIMIZATION으로 분류)

동작: 현재 조건의 baseline etch_score 계산 → Optuna로 개선 후보 탐색 → 상위 최대 3개 후보 반환 → LLM이 한국어 설명 생성

## COMPARISON (비교)

두 가지 공정 조건을 비교할 때 분류된다.

예시 입력:
- "A 조건과 B 조건 비교해줘"
- "위 조건을 source 100 W 올린 값과 비교해줘"

동작: 두 조건(condition_a, condition_b) 각각 예측 수행 → 결과 나란히 반환

## QUESTION (질의응답)

개념이나 도메인 지식에 대한 자유 질문일 때 분류된다.

예시 입력:
- "ion flux가 뭐야?"
- "pressure가 왜 중요해?"
- "source power랑 bias power 차이가 뭐야?"
- "etch rate에 영향을 주는 요소가 뭐야?"

## UNSUPPORTED (미지원)

식각 공정 도메인과 무관하거나 인식할 수 없는 요청일 때 분류된다.

예시 입력:
- "오늘 날씨 어때?"
- "deposition 조건 알려줘"
- "장비 고장났어"

# 입력 파라미터

## 지원 파라미터 목록

| 파라미터 | 단위 | 최솟값 | 최댓값 | 설명 |
|---|---|---|---|---|
| pressure | mTorr | 2.0 | 10.0 | 챔버 내 가스 압력 |
| source_power | W | 100.0 | 500.0 | 플라즈마 생성용 전력 |
| bias_power | W | 0.0 | 1000.0 | 이온 가속용 전력 (0 허용) |

세 파라미터 모두 필수다. 하나라도 누락되면 MISSING 상태로 처리된다.

## 파라미터 유효성 상태

각 파라미터는 추출 후 아래 네 가지 상태 중 하나로 판정된다.

- **VALID**: 범위 내 유효한 값
- **AMBIGUOUS**: 단위가 불명확하거나 해석이 모호한 경우
- **OUT_OF_RANGE**: 허용 범위를 벗어난 값 (예: pressure 1 mTorr → 최솟값 2.0 미만)
- **MISSING**: 사용자 입력에서 해당 파라미터를 찾을 수 없는 경우

파라미터 상태가 VALID가 아니면 예측·최적화·비교를 진행할 수 없다.

## bias_power = 0 특별 처리

bias_power가 정확히 0 W일 때는 ion energy 예측에 별도 모델(`energy_model_off`)을 사용한다.
0이 아닌 경우에는 `energy_model_on`을 사용한다.
이는 bias power 유무에 따라 이온 가속 메커니즘이 달라지기 때문이다.

# 예측 출력값

## 출력 항목

| 출력값 | 단위 | 설명 |
|---|---|---|
| ion_flux | cm⁻² s⁻¹ | 단위 면적·시간당 이온 수 |
| ion_energy | eV | 이온의 평균 에너지 |
| etch_score | point (0~100) | 식각 성능을 나타내는 정규화 지수 |

## 물리적 파생 피처

모델은 입력 파라미터 외에 두 가지 파생 피처를 자동으로 계산하여 예측에 활용한다.

- `source_per_pressure = source_power_w / pressure_mtorr`
- `bias_per_pressure = bias_power_w / pressure_mtorr`

이 비율값은 플라즈마 밀도와 이온 에너지의 물리적 관계를 포착하기 위해 사용된다.

# Etch Score 상세

## 정의

etch_score는 ion_flux와 ion_energy를 결합해 식각 성능을 0~100 범위로 정규화한 상대적 지수다.
절대적인 식각 속도(nm/min) 값이 아니라 학습 데이터 기준의 상대 순위를 나타낸다.

## 계산 공식

```
raw = ion_flux × sqrt(max(ion_energy − 20.0, 0.0))
normalized = (raw − P5) / (P95 − P5) × 100
etch_score = clamp(normalized, 0.0, 100.0)
```

## 20 eV 임계값

공식에서 `max(ion_energy − 20.0, 0.0)`은 ion_energy가 20 eV 미만이면 식각에 기여하지 않음을 의미한다.
20 eV는 스퍼터링(sputtering) 임계값으로, 이 이하의 에너지를 가진 이온은 표면 원자를 제거할 수 없다.

## P5/P95 보정

- **P5 (5th percentile)**: 0.0
- **P95 (95th percentile)**: 7.867448e+17

학습 데이터의 하위 5%~상위 95% 범위를 기준으로 정규화한다.
0점에 가까울수록 식각이 거의 일어나지 않는 조건,
100점에 가까울수록 학습 데이터 내 최상위 수준의 식각 조건을 의미한다.

## etch_score와 etch_rate의 차이

- **etch_rate** (nm/min): 사용자가 실제 장비에서 측정한 실측 식각 속도
- **etch_score** (point): 모델이 계산한 상대적 성능 지수

두 값은 단위도 의미도 다르므로 직접 비교하면 안 된다.
최적화 요청 시 사용자가 현재 etch_rate를 제공하면 참고 정보로만 활용되고,
실제 최적화 기준은 모델이 계산한 etch_score다.

# 예측 모델

## 모델 구성

XGBoost 기반 앙상블 모델로, 하나의 joblib 파일에 세 개의 모델이 저장되어 있다.

| 모델 | 역할 |
|---|---|
| flux_model | ion_flux 예측 (log 스케일 출력 → 10^x 변환) |
| energy_model_on | bias_power > 0 일 때 ion_energy 예측 |
| energy_model_off | bias_power = 0 일 때 ion_energy 예측 |

## 예측 흐름

1. 입력: pressure (mTorr), source_power (W), bias_power (W)
2. 파생 피처 자동 계산: source_per_pressure, bias_per_pressure
3. flux_model → ion_flux (log 출력을 10^x 변환)
4. bias_power 값에 따라 energy_model_on 또는 energy_model_off → ion_energy
5. EtchScoreCalculator → etch_score 계산

# 최적화 동작 방식

## 탐색 전략

Optuna 라이브러리를 사용한 베이즈 최적화(Bayesian Optimization) 기반 탐색이다.

- **탐색 범위**: 입력 파라미터 기준 ±35% 이내
- **시도 횟수**: 200 trials
- **목표**: etch_score 최대화
- **반환**: baseline etch_score보다 높은 결과 중 상위 최대 3개 (중복 점수 제외)

## 탐색 범위 예시

pressure가 5 mTorr인 경우 → 3.25 ~ 6.75 mTorr 범위 내 탐색
(단, 전체 허용 범위 2.0~10.0 mTorr를 벗어나지 않도록 clamp됨)

## 결과가 없는 경우

200회 탐색 후에도 baseline보다 높은 etch_score를 내는 조건을 찾지 못하면
최적화 후보를 반환하지 않는다.
이는 현재 조건이 이미 근방에서 최적에 가까운 상태임을 의미할 수 있다.

## 개선 평가 지표

각 후보에 대해 아래 두 가지 개선 지표를 함께 제공한다.

- **increase_value**: baseline 대비 etch_score 절대 증가량 (point)
- **increase_percent**: baseline 대비 etch_score 증가율 (%)

# 설명(Explanation) 생성

예측 및 최적화 결과에는 LLM이 생성한 한국어 자연어 설명이 포함된다.

## 설명 구성

- **summary**: 결과를 한 문장으로 요약 (etch_score 값 포함)
- **details**: 요청 의도, 입력 조건, 예측 결과, 개선 내용 등을 항목별로 서술한 문장 리스트

## 설명 생성 원칙

- 입력된 데이터만을 근거로 설명하며, 추측이나 엔지니어링 판단을 추가하지 않는다.
- 필드명은 한국어로 번역하지 않고 원문 그대로 사용한다 (예: ion_flux, etch_score)

# 대화 컨텍스트 활용

시스템은 대화 이력(history)을 유지하며, 이전 발화를 참조하는 요청을 처리할 수 있다.

예시:
- "그 조건으로 예측해줘" → 직전 대화에서 언급된 파라미터 재사용
- "위 조건에서 source power 100 W 올려줘" → 이전 조건에서 source_power만 변경
- "위 조건들 비교해줘" → 대화 중 등장한 두 조건을 비교

이전 대화에서 파라미터가 명확히 제시되지 않은 경우에는 MISSING으로 처리된다.

# 지원하지 않는 요청

## 미지원 공정 타입

현재는 ETCH 공정만 지원한다.
Deposition, CVD, PVD 등 다른 공정 유형에 대한 요청은 UNSUPPORTED로 분류된다.

## 미지원 질문 유형

공정과 무관한 일반 질문(날씨, 음악 추천 등)은 UNSUPPORTED로 분류된다.

## 파라미터 범위 초과

허용 범위를 벗어난 파라미터를 입력하면 OUT_OF_RANGE 상태로 반환되며 예측이 진행되지 않는다.

허용 범위:
- pressure: 2.0 ~ 10.0 mTorr
- source_power: 100.0 ~ 500.0 W
- bias_power: 0.0 ~ 1000.0 W

# 시뮬레이션 고정 조건

이 플랫폼의 예측 모델은 K-PLASMA(0D) 시뮬레이터로 생성된 데이터를 학습했다.
시뮬레이션 수행 시 pressure, source_power, bias_power 외 나머지 조건은 아래와 같이 고정되었다.

## 가스 조건

| 항목 | 값 |
|---|---|
| 가스 종류 | Argon (Ar) |
| 가스 유량 | 20.0 sccm |
| 입구 온도 (Tinlet) | 300.0 K |
| 벽 온도 (Tw) | 330.0 K |

Argon 단일 가스만 사용하며, 혼합 가스 조건은 지원하지 않는다.

## 전원 조건

| 항목 | 값 |
|---|---|
| 소스 주파수 | 13.56 MHz |
| 바이어스 주파수 | 2.0 MHz (bias_power > 0인 경우) |
| 바이어스 주파수 (bias off) | 0 Hz (bias_power = 0인 경우) |

소스 전원은 13.56 MHz RF로 플라즈마를 생성하고, 바이어스 전원은 2 MHz RF로 이온을 가속한다.

## 챔버 구조 (TCP 타입)

| 항목 | 값 |
|---|---|
| 플라즈마 반경 (Rp) | 18.0 cm |
| 플라즈마 길이 (Lp) | 13.0 cm |
| 기판 반경 (Rsub) | 10.0 cm |
| 외벽 반경 (R) | 35.0 cm |
| 실드 캡 길이 (Ls) | 10.0 cm |

챔버는 TCP(Transformer Coupled Plasma) 타입의 ICP 반응기 구조다.

## 시뮬레이터 정보

| 항목 | 값 |
|---|---|
| 시뮬레이터 | K-PLASMA(0D) v8.8.1 |
| 개발사 | KWT Solution Inc. |
| 수렴 기준 | 1.0E-8 |
| 모델 유형 | 공간 평균(0D) 플라즈마 수송 모델 |

K-PLASMA(0D)는 공간 평균화된 0차원 플라즈마 수송 모델로, 챔버 전체를 단일 공간으로 처리하여 플라즈마 파라미터를 계산한다.

# 대시보드 그래프 해석

플랫폼 대시보드에는 K-PLASMA(0D) 시뮬레이션 결과로부터 세 가지 그래프가 표시된다.
모든 그래프는 Ar+ 이온을 기준으로 계산된 결과다.

## IED (Ion Energy Distribution, 이온 에너지 분포)

기판에 입사하는 이온의 에너지 분포를 나타낸다.

- **X축**: 이온 에너지 (eV)
- **Y축**: 확률 밀도 (상대적 빈도)

**해석 방법**:
- bias_power = 0 W일 때: 20 eV 부근에 좁은 단일 피크 형성 (sheath 전압이 낮아 이온 가속이 거의 없음)
- bias_power > 0 W일 때: 피크가 고에너지 방향으로 이동하고 분포가 넓어짐
- bias_power가 높을수록 고에너지 이온 비율이 증가하여 식각 효율이 높아짐
- 분포의 평균값이 이 플랫폼에서 예측하는 ion_energy (eV)에 해당함

## IAD (Ion Angular Distribution, 이온 각도 분포)

기판 법선 방향을 기준으로 이온이 입사하는 각도 분포를 나타낸다.

- **X축**: 입사 각도 (degree, 0°= 기판 법선 방향)
- **Y축**: 확률 밀도 (상대적 빈도)

**해석 방법**:
- 0° 부근에 피크가 집중될수록 이온이 수직으로 입사 → 이방성(anisotropic) 식각에 유리
- bias_power가 높을수록 이온이 더 수직으로 가속되어 분포가 0° 부근으로 집중됨
- 피크가 넓게 퍼질수록 등방성(isotropic) 식각 특성을 나타냄
- 미세 패턴 식각에서는 IAD가 좁을수록 측벽 손상이 적고 식각 프로파일이 수직에 가까워짐

## CUR (Current Density, 전류 밀도)

바이어스 전극에서 시간에 따른 전류 밀도 파형을 나타낸다.

- **X축**: 시간 (RF 사이클 기준, ns 또는 μs)
- **Y축**: 전류 밀도 (A/m²)

**해석 방법**:
- bias_power = 0 W일 때: 전류 파형이 없거나 매우 작음
- bias_power > 0 W일 때: 2 MHz RF 주파수에 따른 주기적 파형이 나타남
- 전류 밀도의 진폭이 클수록 기판에 전달되는 이온 에너지가 높음
- 파형의 비대칭성(DC self-bias)이 이온 가속의 주요 원인

## 그래프 간 관계

```
source_power 증가 → 이온 밀도 증가 → IED 피크 높이 증가, IAD 형태 유지
bias_power 증가  → sheath 전압 증가 → IED 피크 고에너지 이동, IAD 0° 집중, CUR 진폭 증가
pressure 증가    → 충돌 증가 → IED 분포 넓어짐, IAD 분포 넓어짐 (등방성 증가)
```

# 입력 방법 / 단위 가이드

## 허용 단위 및 변환

사용자가 다른 단위로 입력해도 시스템이 자동으로 변환하여 처리한다.

| 파라미터 | 기본 단위 | 허용 입력 예시 | 변환 규칙 |
|---|---|---|---|
| pressure | mTorr | "5 mTorr", "0.005 Torr", "5" | Torr 입력 시 × 1000 변환 |
| source_power | W | "300 W", "0.3 kW", "300" | kW 입력 시 × 1000 변환 |
| bias_power | W | "50 W", "0.05 kW", "0" | kW 입력 시 × 1000 변환 |

단위를 명시하지 않은 숫자만 입력한 경우, 맥락에 따라 기본 단위(mTorr, W)로 해석한다.
단위가 불명확하거나 해석이 모호한 경우에는 AMBIGUOUS 상태로 처리된다.

## 자연어 입력 예시

시스템은 구조화된 입력뿐만 아니라 자연어 문장도 처리한다.

- "pressure 5, source 300, bias 50으로 예측해줘"
- "pressure는 5 mTorr, source power는 0.3 kW, bias는 50 W 조건으로 예측"
- "위 조건에서 bias 없애고 예측해줘" → bias_power = 0 으로 해석
- "pressure 5 mTorr, source 300 W, bias 50 W 조건과 bias를 100 W로 바꾼 조건을 비교해줘"

## 자주 혼동되는 단위

- Torr vs mTorr: 1 Torr = 1000 mTorr. 실험실에서는 mTorr를 주로 사용.
- kW vs W: 1 kW = 1000 W. 장비 스펙시트에서는 kW로 표기하기도 함.
- sccm: 가스 유량 단위로, 이 플랫폼에서는 20.0 sccm으로 고정되어 입력 불필요.

# 오류 상황 대처법

## AMBIGUOUS (모호한 입력)

**발생 원인**: 단위가 불명확하거나 수치 해석이 모호한 경우

예시: "source 0.3으로 예측해줘" → 0.3 W인지 0.3 kW(=300 W)인지 불명확

**해결 방법**: 단위를 명시하여 재입력
- "source 0.3 kW로 예측해줘" 또는 "source 300 W로 예측해줘"

## OUT_OF_RANGE (범위 초과)

**발생 원인**: 입력값이 허용 범위를 벗어난 경우

허용 범위:
- pressure: 2.0 ~ 10.0 mTorr
- source_power: 100.0 ~ 500.0 W
- bias_power: 0.0 ~ 1000.0 W

**해결 방법**: 허용 범위 내의 값으로 재입력

예시: "pressure 1 mTorr" → 최솟값인 2.0 mTorr 이상으로 재입력 필요

**주의**: 범위를 벗어난 조건은 모델의 학습 데이터 범위 밖이므로 예측 정확도를 보장할 수 없다.

## MISSING (파라미터 누락)

**발생 원인**: 세 파라미터(pressure, source_power, bias_power) 중 하나 이상이 입력에 없는 경우

**해결 방법**: 누락된 파라미터를 포함하여 재입력

예시: "bias 없이 예측해줘" → bias_power = 0 W로 명시하거나 "bias 0으로 설정해줘" 추가

## 파이프라인 진행 불가 상황

AMBIGUOUS, OUT_OF_RANGE, MISSING 상태 중 하나라도 있으면 예측·최적화·비교 파이프라인이 진행되지 않는다.
시스템은 어떤 파라미터에 문제가 있는지 응답에 명시한다.

# etch_score 실용적 해석 기준

etch_score는 학습 데이터 내 상대 순위를 나타내는 지수다. 절대적인 식각 속도가 아닌 상대적 비교에 활용해야 한다.

## 점수 구간별 해석

| 점수 범위 | 해석 |
|---|---|
| 0 ~ 20 | 식각이 거의 일어나지 않는 조건 (낮은 ion_flux 또는 ion_energy ≤ 20 eV) |
| 20 ~ 50 | 중간 이하 수준의 식각 성능 |
| 50 ~ 75 | 중간 이상 수준의 식각 성능 |
| 75 ~ 90 | 높은 수준의 식각 성능 |
| 90 ~ 100 | 학습 데이터 내 최상위 수준의 식각 성능 |

## 점수 해석 시 주의사항

- etch_score는 학습 데이터(150개 시뮬레이션 포인트)를 기준으로 계산된 상대 지수다.
- 동일 점수라도 조건(pressure/source_power/bias_power 조합)이 다르면 실제 공정 결과는 다를 수 있다.
- bias_power = 0 W이면 ion_energy가 20 eV에 근접하여 etch_score가 낮게 나오는 경향이 있다.
- 최적화 결과에서 baseline 대비 증가량(increase_value, increase_percent)을 함께 확인하면 개선 효과를 판단하는 데 도움이 된다.

## etch_score와 실제 식각 속도의 관계

etch_score가 높을수록 실제 식각 속도(etch rate, nm/min)도 높은 경향이 있지만, 단순 선형 관계는 아니다.
실제 장비에서의 etch rate는 장비 상태, 가스 종류, 마스크 재질 등 이 플랫폼이 고려하지 않는 요소에 의해 영향을 받는다.

# 모델 학습 데이터 범위와 한계

## 학습 데이터 구성

K-PLASMA(0D) 시뮬레이터로 생성한 150개 시뮬레이션 데이터 포인트를 학습에 사용했다.

| 파라미터 | 값 구성 | 포인트 수 |
|---|---|---|
| pressure | 2, 4, 6, 8, 10 mTorr | 5종 |
| source_power | 100, 200, 300, 400, 500 W | 5종 |
| bias_power | 0, 200, 400, 600, 800, 1000 W | 6종 |

총 5 × 5 × 6 = 150개의 격자점(grid point) 조건에서 시뮬레이션을 수행했다.

## 예측 정확도 특성

- **격자점 내부 예측**: 학습 데이터 격자 내 조건은 보간(interpolation) 영역으로, 예측 정확도가 높다.
- **경계 근처 예측**: 허용 범위의 경계(예: pressure 2 mTorr, source 100 W)에서는 외삽(extrapolation) 영역과 가까워 정확도가 낮아질 수 있다.
- **격자 간 중간값**: 학습 데이터에 없는 중간 조건(예: pressure 3 mTorr)은 XGBoost의 일반화 능력에 의존한다.

## 모델의 한계

1. **가스 종류 고정**: Argon 단일 가스 조건만 학습했으므로 다른 가스(CF₄, O₂ 등) 조건에는 적용 불가.
2. **챔버 구조 고정**: TCP 타입 ICP 챔버의 특정 치수(Rp=18cm, Lp=13cm 등)에서만 유효.
3. **0D 모델 한계**: 공간 평균 모델로 챔버 내 공간적 불균일성(uniformity)을 반영하지 못한다.
4. **외삽 불가**: 허용 범위를 벗어난 조건에서는 예측 신뢰도를 보장할 수 없다.
5. **실제 장비 오차**: 시뮬레이션 기반 학습 데이터와 실제 장비 측정값 사이에는 차이가 있을 수 있다.

# 플라즈마 기초 용어

이 섹션은 플라즈마 공정에 익숙하지 않은 사용자를 위한 기초 용어 설명이다.

## 단위

| 단위 | 설명 |
|---|---|
| mTorr | 압력 단위. 1 Torr의 1/1000. 진공 공정에서 주로 사용. 1 mTorr ≈ 0.133 Pa |
| sccm | 가스 유량 단위. Standard Cubic Centimeter per Minute. 표준 상태에서 분당 흐르는 가스 부피 |
| eV (전자볼트) | 에너지 단위. 1 eV ≈ 1.6 × 10⁻¹⁹ J. 이온 에너지 표현에 사용 |
| W (와트) | 전력 단위. 플라즈마 생성(source)과 이온 가속(bias)에 사용되는 RF 전력 |
| MHz | 주파수 단위. 소스 전원 13.56 MHz, 바이어스 전원 2 MHz |

## 플라즈마 공정 용어

| 용어 | 설명 |
|---|---|
| ICP | Inductively Coupled Plasma. 코일에 흐르는 RF 전류가 유도하는 자기장으로 플라즈마를 생성하는 방식 |
| TCP | Transformer Coupled Plasma. ICP의 일종으로 변압기 원리를 이용한 구조. 이 플랫폼의 챔버 타입 |
| RF | Radio Frequency. 플라즈마 생성 및 이온 가속에 사용하는 고주파 전력 |
| Source Power | 플라즈마 생성용 전력. 높을수록 이온 밀도(ion flux) 증가 |
| Bias Power | 이온 가속용 전력. 기판에 인가하여 이온이 기판 쪽으로 가속되게 함. 높을수록 이온 에너지 증가 |
| Ion Flux | 단위 면적·시간당 기판에 입사하는 이온 수 (cm⁻²s⁻¹). 식각 속도와 직접 관련 |
| Ion Energy | 기판에 입사하는 이온의 평균 에너지 (eV). 식각 선택성과 손상 깊이에 영향 |
| Sheath | 기판 표면 근처의 전기적 경계층. 이온이 sheath 전압에 의해 가속되어 기판에 입사 |
| Sputtering | 이온이 표면에 충돌하여 원자를 떼어내는 물리적 식각 메커니즘. 임계 에너지(약 20 eV) 이상에서 발생 |
| Etch Rate | 식각 속도 (nm/min). 단위 시간당 제거되는 막의 두께 |
| Anisotropic | 이방성 식각. 수직 방향으로만 식각이 일어나 패턴의 측벽이 수직에 가까움 |
| Isotropic | 등방성 식각. 모든 방향으로 동일하게 식각이 일어남 |

# 자주 묻는 질문 (FAQ)

## 소스 파워(source_power)를 높이면 이온 플럭스(ion_flux)가 어떻게 변하나요?

소스 파워(source_power)를 높이면 플라즈마 생성 전력이 증가하여 전자 밀도가 올라가고, 그 결과 이온 밀도가 증가하므로 이온 플럭스(ion_flux)가 증가한다.
즉, 소스 파워 ↑ → 플라즈마 밀도 ↑ → 이온 플럭스(ion_flux) ↑ 관계다.
반면 바이어스 파워(bias_power)는 ion_flux에 큰 영향을 주지 않으며 주로 이온 에너지(ion_energy) 가속에 영향을 미친다.

## 바이어스 파워(bias_power)를 높이면 어떻게 되나요?

바이어스 파워(bias_power)를 높이면 sheath 전압이 증가하여 이온이 기판 쪽으로 더 강하게 가속된다.
그 결과 이온 에너지(ion_energy)가 증가하고, 고에너지 이온 비율이 높아져 식각 성능(etch_score)이 증가하는 경향이 있다.
바이어스 파워는 이온 플럭스(ion_flux)보다 이온 에너지(ion_energy)에 주로 영향을 준다.

## 압력(pressure)이 높아지면 어떻게 되나요?

pressure가 높아지면 가스 분자 간 충돌이 증가하여 이온의 방향성이 감소하고, 등방성 식각 특성이 강해진다.
또한 이온 에너지 분포가 넓어지고 방향성이 줄어들어 이방성 식각(anisotropic)이 어려워진다.
일반적으로 낮은 압력 조건이 이방성 식각에 유리하다.

## CF4, O₂ 등 다른 가스로 식각할 수 있나요?

아니다. 이 플랫폼은 현재 Argon(Ar) 단일 가스 조건만 지원한다.
CF₄, O₂, Cl₂ 등 다른 가스 종류는 지원하지 않는다.
모델이 Argon 조건 데이터만으로 학습되었으므로, 다른 가스를 사용하는 식각 공정에는 적용할 수 없다.

## 500mTorr처럼 허용 범위를 벗어나면 어떻게 되나요?

허용 범위를 벗어난 값을 입력하면 해당 파라미터가 OUT_OF_RANGE 상태로 처리되어 예측이 진행되지 않는다.
pressure의 허용 범위는 2.0 ~ 10.0 mTorr이므로, 500mTorr는 범위를 크게 벗어나 예측 불가 상태로 처리된다.
허용 범위 내 값으로 재입력해야 예측이 가능하다.

## etch_score가 낮게 나왔을 때 개선 방법은?

etch_score를 높이려면 일반적으로 source_power와 bias_power를 함께 높이는 것이 효과적이다.
source_power를 높이면 ion_flux가 증가하고, bias_power를 높이면 ion_energy가 증가하여 etch_score가 향상된다.
최적화 기능(OPTIMIZATION 태스크)을 사용하면 시스템이 자동으로 개선 조건을 탐색해준다.

# 전자 밀도 / 전자 온도

## 이 플랫폼에서 직접 예측하지 않는 이유

이 플랫폼은 **ion_flux**와 **ion_energy**를 직접 예측하며, 전자 밀도(electron density, ne)와 전자 온도(electron temperature, Te)는 별도로 예측하지 않는다.

그 이유:
1. **사용 목적**: 플랫폼의 목표는 식각 결과 예측이며, 식각 성능은 이온의 특성(flux, energy)으로 직접 결정된다.
2. **간접 반영**: 전자 밀도와 온도는 이미 ion_flux와 ion_energy 예측 모델에 간접적으로 반영되어 있다. K-PLASMA(0D) 시뮬레이터가 전자 거동을 계산하여 이온 특성을 출력하기 때문이다.
3. **사용자 편의**: 공정 엔지니어는 플라즈마 내부 상태보다 기판에서의 결과(이온 flux와 energy)에 더 직접적인 관심을 갖는다.

## 전자 밀도와 식각의 관계

전자 밀도(ne)는 이온 밀도와 거의 동일하며(준중성 조건), ion_flux와 강한 상관관계를 갖는다.

- source_power가 높을수록 전자 밀도 증가 → ion_flux 증가
- pressure가 낮을수록 전자 온도 증가 → 이온 생성 효율에 영향

전자 온도(Te)는 일반적으로 1~5 eV 범위이며, 이온화율과 반응 화학에 영향을 준다.
이 플랫폼에서는 Argon 단일 가스 조건에서 이 효과가 이미 학습 데이터에 내재되어 있다.

## K-PLASMA(0D) 시뮬레이터와의 관계

K-PLASMA(0D)는 내부적으로 전자 에너지 방정식을 풀어 전자 밀도, 전자 온도, 이온 밀도 등을 계산한다.
이 플랫폼은 그 최종 출력값인 ion_flux와 ion_energy만을 XGBoost 모델로 재현한다.
따라서 전자 밀도/온도에 대한 상세 정보가 필요한 경우에는 K-PLASMA(0D) 시뮬레이터를 직접 사용해야 한다.
